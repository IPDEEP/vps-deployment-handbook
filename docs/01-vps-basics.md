# 01｜VPS 是什么？与云服务器、独立服务器有什么区别？

## 1. VPS 的基本概念

VPS（Virtual Private Server，虚拟专用服务器）通常是通过虚拟化技术，将一台物理服务器的计算资源划分为多个相互隔离的虚拟服务器实例。每个实例可以拥有自己的操作系统环境、分配的 CPU、内存、磁盘和网络资源。

具体隔离方式、资源保证和管理权限取决于服务商的虚拟化架构与产品方案。

## 2. VPS、云服务器和独立服务器

| 类型 | 常见特点 | 需要关注 |
|---|---|---|
| VPS | 在物理主机上运行的虚拟服务器实例 | 虚拟化类型、资源限制、磁盘和网络 |
| 云服务器 | 通常由云平台提供，可结合云网络、镜像和管理服务 | 计费方式、可扩展性、云平台功能 |
| 独立服务器 | 整台物理服务器资源主要由单一租户使用 | 硬件规格、维护责任、成本和交付周期 |

市场上“VPS”和“云服务器”的产品边界并不完全统一，不能只凭商品名称判断底层技术或服务等级。

## 3. VPS 常见用途

- 网站和 Web 应用部署；
- API 服务和开发测试环境；
- 数据处理和定时任务；
- 自建监控、日志或内部工具；
- 学习 Linux、网络和服务器运维。

用途不同，对 CPU、内存、存储、带宽和可用性的要求也不同。

## 4. 购买前需要确认

1. CPU 型号、核心数及是否存在共享限制；
2. 内存容量和是否支持扩展；
3. 磁盘类型、容量和 IOPS 说明；
4. 带宽、流量额度和超额规则；
5. 数据中心地区及网络路由；
6. 操作系统镜像和控制台功能；
7. 备份、快照和救援模式；
8. 服务条款、退款规则和技术支持范围。

## 5. 不要只比较价格

低价套餐可能在 CPU 调度、磁盘性能、带宽、流量、备份或支持服务方面存在差异。应以可验证的规格和业务测试结果为依据。
