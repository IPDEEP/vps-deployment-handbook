# 12｜VPS 基础安全检查清单

服务器安全需要持续维护，不能依赖单次初始化操作。

## 1. 账号与权限

- [ ] 日常使用普通账户；
- [ ] 仅为必要用户授予 sudo；
- [ ] 定期清理离职或不再使用的账户；
- [ ] 不共享个人 SSH 私钥；
- [ ] 为重要密钥设置口令并安全保存。

## 2. SSH

- [ ] 确认 SSH 端口和认证方式；
- [ ] 使用可信渠道核对主机指纹；
- [ ] 优先采用密钥认证；
- [ ] 修改配置前保留现有会话；
- [ ] 从新会话验证配置；
- [ ] 确保存在服务商控制台救援方式。

## 3. 防火墙与网络

- [ ] 只开放业务需要的端口；
- [ ] 同时检查云安全组和系统防火墙；
- [ ] 数据库和管理服务不无必要地暴露公网；
- [ ] 定期检查监听端口；
- [ ] 检查不再使用的服务。

## 4. 系统与软件

- [ ] 了解发行版支持周期；
- [ ] 定期安装安全更新；
- [ ] 监控关键服务状态；
- [ ] 移除不需要的软件和服务；
- [ ] 记录重要配置变更。

## 5. 数据和备份

- [ ] 明确关键数据范围；
- [ ] 定期备份；
- [ ] 加密敏感备份；
- [ ] 保留异地副本；
- [ ] 定期执行恢复演练；
- [ ] 限制备份删除权限。

## 6. 日志与监控

- [ ] 监控 CPU、内存、磁盘和网络；
- [ ] 监控 Web 与应用服务；
- [ ] 设置磁盘空间告警；
- [ ] 保护日志中的个人信息和凭据；
- [ ] 为安全事件保留必要审计记录。

## 7. 事件响应

发现异常登录、凭据泄露或恶意进程时，应按组织流程隔离受影响资源、保留必要证据、轮换凭据、检查持久化机制并恢复可信服务。高风险事件应寻求专业安全人员协助。
