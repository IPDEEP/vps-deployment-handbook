# 02｜VPS 配置怎么选？CPU、内存、磁盘和带宽说明

VPS 选型应从实际应用负载出发，而不是单纯追求更高的配置数字。

## 1. CPU

CPU 影响程序执行和并发处理能力。选型时关注：

- 分配的 vCPU 数量；
- CPU 型号或代际（服务商有提供时）；
- 是否存在持续负载限制；
- 是否为共享资源；
- 应用是否属于计算密集型。

静态展示型网站、轻量 API、编译任务和数据库服务的 CPU 需求不同。

## 2. 内存

内存用于运行操作系统、应用进程、缓存和数据库等。内存不足可能引发进程被系统终止、频繁使用 Swap 或服务响应变慢。

部署前可列出计划运行的服务，估算基础占用并预留系统和峰值空间。不要把某个固定内存数字当作所有网站的通用标准。

## 3. 磁盘

需要关注：

- 容量；
- SSD / NVMe 等介质类型；
- IOPS 或吞吐限制（如有说明）；
- 快照和备份能力；
- 数据盘与系统盘的布局。

数据库、日志密集型应用和普通静态网站的磁盘性能需求不同。

## 4. 带宽与流量

带宽表示传输能力，常以 Mbps 或 Gbps 表示；流量通常指计费周期内累计传输的数据量，常以 GB 或 TB 表示。

购买时确认：

- 上行和下行是否对称；
- 峰值带宽还是保证带宽；
- 月流量额度；
- 超额后的限速、计费或停机规则；
- 是否存在端口速率或区域网络限制。

## 5. 地区选择

选择服务器地区时，应考虑主要访问用户所在区域、目标服务的网络位置、合规要求、数据存储要求和实际路由表现。

服务器物理地区不一定等于用户访问时的最佳网络路径。应通过实际测试评估延迟、丢包和稳定性。

## 6. 按用途初步评估

| 用途 | 优先关注 |
|---|---|
| 个人网站或博客 | 内存、磁盘、备份和带宽 |
| Web API | CPU、内存、网络和并发 |
| 数据库 | 内存、磁盘 I/O、备份和恢复 |
| 开发测试 | 快照、系统镜像、管理便利性 |
| 文件服务 | 磁盘容量、吞吐、备份和访问控制 |

## 7. 采购检查清单

- [ ] 规格单位和资源限制是否清楚？
- [ ] 带宽和流量规则是否明确？
- [ ] 数据中心地区是否符合业务要求？
- [ ] 是否支持所需操作系统？
- [ ] 是否有控制台或救援模式？
- [ ] 备份与快照如何收费？
- [ ] 服务条款和退款政策是否清楚？
